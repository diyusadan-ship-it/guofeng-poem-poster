# 诗词分析指南

拿到一首古诗词后，按本文件完成 8 项拆解。所有拆解结果最终都会流进**完整海报提示词**（AI 一次性直出插画+标题+诗句+署名+朱印），因此分析深度直接决定最终海报质量。

## 核心原则

**让 AI 当"画完整海报的画师"，不是"画底图的画匠"。**

提示词要让模型看到：诗意是什么关系、场景怎么组织、文字放在哪里、色彩怎么分层。信息越具体，AI 画出来的画面越可信。

**不要先找"漂亮场景"，先找"诗意关系"。**

诗意关系是全诗里那个核心张力——远近、高低、动静、冷暖、聚散、时间变化、情感转折。找对了关系，景物安排、色彩和文字都会跟着就位。

## 一、找诗意关系

### 常见的 8 种关系

- **远近**：如「大漠孤烟直，长河落日圆」——沙漠（近）与落日（远）的尺度对比
- **高低**：如「黄河之水天上来，奔流到海不复回」——从高山到海平面的落差
- **动静**：如「明月松间照，清泉石上流」——松间的静态月光与流动的清泉
- **冷暖**：如「寒雨连江夜入吴」——冷雨与暖江水的对比
- **聚散**：如「劝君更尽一杯酒，西出阳关无故人」——席间的聚与出关的散
- **时间变化**：如「绿肥红瘦」——春夏之交的花期转换
- **情感转折**：如「人生得意须尽欢，莫使金樽空对月」——得意转及时行乐
- **虚实**：如「欲穷千里目，更上一层楼」——实际登高与想象的千里

### 判定标准

好的诗意关系同时满足：

1. **能对应到画面元素**——不是抽象的情感概念，是可以在画里画出来的对比
2. **有主次**——不是五个关系并列，是一个主导、一两个辅助
3. **能承载文字**——文字的位置和节奏也能体现这个关系

## 二、找戏眼

### 从以下常见动作里挑

古人诗词里的戏眼高度集中在这些动作上：

- **手部动作**：卷帘、把酒、停笔、掩袖、抚琴、抚剑、掩门、扶栏、拾瓣、拂衣、拢发、指向、执扇
- **头部动作**：倚楼、低头、抬眼、回头、照镜、侧耳、听雨、望月、远眺、微蹙
- **身体动作**：独坐、倚床、行舟、策马、夜归、独行、登楼、临水
- **物件反应**：烛焰摇、酒盏倾、笔搁案、帘动风来、花瓣落、钟声远

### 判定标准

好的戏眼同时满足：

1. **具体**——画面里能一眼看到，不用解释
2. **克制**——不是戏剧化动作（不哭不笑不甩袖）
3. **有停顿**——动作处于"将做未做"或"刚做完"的临界点，不是完成态
4. **能承载情绪**——动作本身就能让观者体会到诗里的情绪

### 反面例子

| 反例 | 问题 | 修正 |
|---|---|---|
| "她望着明月思念故乡" | "思念"是情绪不是动作 | "她倚在窗前，手停在窗棂上" |
| "诗人骑马远行" | 太泛，无戏剧张力 | "诗人勒马回头望城，帽带被风吹起" |
| "他在月下饮酒" | 泛古风，任何诗都能套 | "他半斜倚在案边，酒盏倾斜将洒未洒" |

## 三、提取核心意象

从戏眼出发，向四周补 2–4 个具体可拍的意象。意象必须是**名词**——花、月、酒、剑、舟、烛、帘、镜、山、水、竹、柳、梅、鹤、鹿。

### 意象来源优先级

1. **诗里明确出现的**——首选。如《静夜思》"举头望明月"，"月"就是必选意象
2. **诗里隐含但合理推断的**——次选。如"举杯消愁"，"酒盏"就是必选
3. **符合时代质感的道具**——补充。唐代：木窗、竹帘、青瓷、矮榻、香炉、素绢、团扇、庭院植物
4. **纯装饰性意象**——不选。不因为"美"就加龙、凤、祥云

### 意象数量控制

- 短诗（绝句、律诗）：2–3 个意象，画面越简越好
- 中词：3–4 个意象
- 长调：4–5 个意象，但要有主次

## 四、定色彩层级

原文的明确要求：「根据诗意建立**主色、辅助色与点睛色**关系，不固定使用同一套配色」。

### 三种定色路径

**路径 A：跟随节气/物候**

| 场景 | 主色 | 辅助色 | 点睛色 |
|---|---|---|---|
| 春晨 | 淡鹅黄 | 嫩绿、海棠粉 | 胭脂（花瓣） |
| 夏午 | 深绿 | 蝉鸣白、荷塘红 | 朱砂 |
| 秋夕 | 金黄 | 深褐、冷灰蓝 | 胭脂 |
| 冬夜 | 墨黑 | 月白、烛黄 | 朱砂 |

**路径 B：跟随情绪**

| 情绪 | 主色 | 辅助色 | 点睛色 |
|---|---|---|---|
| 旷达豪放 | 石青 | 剑金 | 朱砂 |
| 孤寂清冷 | 花青 | 银白、冷灰 | 朱砂 |
| 温柔婉约 | 淡鹅黄 | 藕荷、象牙白 | 胭脂 |
| 怅惘怀旧 | 赭红 | 素绢白 | 落梅红 |
| 忧国悲愤 | 石青 | 血色、墨黑 | 朱砂 |

**路径 C：跟随原诗的关键词**

- 有"月"：主色月白 + 辅助色冷青蓝 + 点睛色朱砂
- 有"烛""灯"：主色烛黄 + 辅助色墨黑 + 点睛色朱砂
- 有"雪"：主色素白 + 辅助色冰青 + 点睛色胭脂
- 有"酒"：主色赤褐 + 辅助色象牙白 + 点睛色朱砂
- 有"梅"：主色雪白 + 辅助色落梅红 + 点睛色朱砂
- 有"黄河""大漠"：主色藤黄+赭红 + 辅助色石青（远景夜空）+ 点睛色银白（星光）

### 传统色词库（给 AI 用）

| 中文 | 英文 | 常见用途 |
|---|---|---|
| 石青 | mineral blue / azurite | 深色调、天空、远景 |
| 石绿 | malachite green | 植物、远景山峦 |
| 朱砂 | cinnabar / vermilion | 点睛、印章、花蕊 |
| 赭红 | ochre red | 土色、墙面 |
| 胭脂 | rouge | 花瓣、点缀 |
| 藤黄 | gamboge | 嫩叶、点染 |
| 花青 | flower indigo | 深色轮廓 |
| 暖米白 | warm off-white / cream | 留白、纸本底 |

### 留白规则

- 暖米白留白占画面 20-30%，参与空间组织
- 留白位置必须由场景决定，不是随便留一片空白
- 留白要被景物"包围"，而不是零散的小碎片
- 标题、诗句要放在留白区域或深色连续色面上，避免放在密集景物上

## 五、定情绪氛围

用一个词 + 一句具体化描述，把情绪翻译成画面语言。

### 情绪词库

- **旷达**："山月不知心，唯有长啸意"——豪迈但不狂，克制中有释放
- **孤寂**："独坐幽篁里"——不是凄惨，是一个人待得安稳
- **怅惘**："绿肥红瘦"——不是哭，是心里明白春将尽却说不出口
- **清旷**："孤舟蓑笠翁"——冷，但不悲，是自然与人的平静对话
- **婉约**："寻寻觅觅"——不是绝望，是心里的空缺一笔一笔画给观者看
- **悲愤**："凭谁问"——情绪压抑到极限，画面里必须有一处"压不下去"的裂痕
- **豪放浪漫**："直上银河去"——沙涛上银河，是想象力，不是抒情
- **恬淡**："采菊东篱下"——不是清高，是与自然的和谐相处

### 情绪不能落回情绪

写完情绪词后，必须补一句"这在画面里长什么样"：

- 错："情绪是孤寂"
- 对："孤寂 → 画面里只有一个人，桌上一盏未喝完的酒，窗外月色清冷，无第二人物"
- 错："情绪是豪放"
- 对："豪放 → 画面里黄河占据下部三分之一，诗人立于河岸举手指向横跨夜空的银河，人物占画面 5-8%，天地对话"

## 六、规划构图

原文的明确要求：「采用高位俯瞰、东方散点透视与现代平面构成」+「根据诗意选择自然曲线、偏心布局、对角呼应、开合关系或疏密变化」。

### 常见构图类型

**类型 A：横向三分（河海、山水）**

- 前景（下 1/3）：人物、近景
- 中景（中 1/3）：过渡景物
- 远景（上 1/3）：天空、山水、云气

适用：《浪淘沙》《登高》《登高望远》这类有"空间纵深"的诗

**类型 B：纵向散点（人物+景物）**

- 主体人物在画面偏左或偏右
- 景物在人物周围散点分布
- 留白在人物对面一侧

适用：《静夜思》《饮酒》这类有"人物特写"的诗

**类型 C：对角线构图（动静结合）**

- 主体景物沿对角线布局
- 对角线的另一端是留白或文字区
- 观看路径从近到远或从远到近

适用：《赤壁赋》《念奴娇》这类有"情感转折"的诗

**类型 D：圆形构图（月/镜/窗）**

- 主体是圆形意象（月、镜、窗棂、井）
- 景物围绕圆形分布
- 中央圆形是视觉焦点

适用：《静夜思》《月下独酌》《咏月》这类以圆形意象为主的诗

### 观看路径

构图要有一条"观看路径"——引导视线从标题进入核心意象、再流到诗句和署名。常见的观看路径：

- **从上到下**：标题在顶，景物在中间，诗句和署名在底
- **从左到右**：景物在左，文字在右（配合竖排诗句）
- **从近到远**：人物在近景，景物向远处延伸（配合横向三分构图）
- **对角线**：文字在左上，景物在右下（配合对角线构图）

## 七、规划文字版式

这是**关键一步**——因为原文要求 AI 直出文字，文字位置决定整体版式。

### 四个文字元素的位置规则

**1. 标题（诗词标题）**

- **位置**：优先在顶部（横排）或右侧（竖排），避开核心意象
- **字号**：占画面 8-15%，是全图最大的字
- **字体**：暖白色书法字，或与细线设色画风协调的自然书写体
- **规则**：不固定在某个角落，根据核心意象位置调整；不将词意单位随意拆散（如"浪淘沙"三字不能拆成两行）
- **背景**：放在连续的深色色面上（如夜空、深绿植被），避开暖米白留白和密集枝条

**2. 诗句（入画原文）**

- **位置**：优先与标题对侧，或对角呼应
- **字号**：小型，占画面 3-8%
- **字体**：端正、易辨认的字体，避免过于艺术化
- **排布**：纵排为主，遵循从上到下、从右向左的阅读顺序
- **规则**：
  - 严格按原文本，不擅自改写、补全、添加其他文案
  - 保留准确文字、字序与标点
  - 标点符合纵排习惯（如句号在右下角，不在行尾）
- **空间安排**：文字较多时，优先减少辅助景物、扩大完整文字区域

**3. 作者署名**

- **位置**：通常在诗句下方或左侧，与诗句建立对齐关系
- **字号**：小型，比诗句略小
- **规则**：全图只出现一次
- **朱印**：附近可安排一枚克制的小朱印，不添加无关文字或伪造签名

**4. 朱印**

- **位置**：靠近作者署名或诗句
- **样式**：方形或椭圆形小印
- **内容**：通常刻"诗人姓氏"或"诗题关键词"（如"刘"、"禹"、"静夜"、"银河"）
- **规则**：不在印中添加无关文字、口号或伪造签名

### 文字位置示意

```
┌─────────────────────────────┐
│  [标题]                     │ ← 顶部或右上
│                             │
│        [核心意象]            │
│                             │
│                             │
│  [诗句]  ·                 │ ← 中景偏左
│  [署名] [朱印]              │
│                             │
│        [远景]                │
└─────────────────────────────┘
```

### 反面例子

- ❌ 标题占画面 40%，喧宾夺主
- ❌ 诗句排在密集枝条上，几乎看不清
- ❌ 标题和诗句挤在同一角落，无阅读秩序
- ❌ 朱印盖在核心意象上
- ❌ 标题竖排但字序混乱，词意单位被拆散

## 八、挑入画佳句

从全诗里挑 1–2 句进海报。

### 挑选原则

1. **有戏眼的句子优先**——比如"举头望明月"比"床前明月光"更合适
2. **短、有画面感**——10–14 字为宜，不超过 20 字
3. **能代表全诗**——不是最华丽的一句，是最能概括全诗情绪的一句
4. **视觉可承载**——句子里必须有具体的名词（月、山、舟、酒……），全是抽象词的句子不要选
5. **有情感爆点**——如果是长诗，选最能代表全诗"情感转折"的一句

### 反面例子

| 句子 | 是否入画 | 原因 |
|---|---|---|
| "举头望明月" | ✅ | 有动作、有对象、能拍 |
| "疑是地上霜" | ❌ | 是比喻不是动作，画面表达不了"疑" |
| "独在异乡为异客" | ⚠️ | 情绪好但意象稀薄，需配第二句 |
| "每逢佳节倍思亲" | ❌ | 纯抒情，无画面 |
| "绿肥红瘦" | ✅ | 4 个字全是意象，色彩浓、有对比 |
| "知否知否" | ❌ | 语气词，画面无法表达 |
| "直上银河去" | ✅ | 有动作、有对象、有情感爆点 |

## 拆解示例

### 《浪淘沙·其一》—— 刘禹锡

- **诗意关系**：远近 + 情感转折（眼前黄河→天上银河，从壮阔转向浪漫向往）
- **戏眼**：诗人立于黄河岸边，举手指向银河
- **意象**：黄河、沙浪、银河、牵牛织女星
- **色彩层级**：
  - 主色：藤黄+赭红（河沙金黄）
  - 辅助色：石青+花青（远景夜空墨蓝）
  - 点睛色：银白（星光）、朱砂（印章）
- **情绪**：豪放浪漫——沙涛上银河，是想象力，不是抒情
- **构图**：横向三分 + 银河对角线（从下黄沙浪向上延伸）
- **文字版式**：
  - 标题「浪淘沙」在右上（横排，暖白书法字，占 10%）
  - 诗句「直上银河去，同到牵牛织女家」纵排，从右向左分两列，在左上
  - 作者署名「刘禹锡」在诗句下方
  - 朱印在左下角，刻「银」字
- **入画佳句**：直上银河去，同到牵牛织女家

### 《静夜思》—— 李白

- **诗意关系**：远近 + 冷暖（室内烛火暖、室外月光冷）
- **戏眼**：李白从床上坐起，抬头看向窗外明月
- **意象**：月、床、窗棂、孤烛
- **色彩层级**：
  - 主色：墨黑（夜色）
  - 辅助色：月白、烛黄
  - 点睛色：朱砂
- **情绪**：孤寂——画面里只有一个人，桌上一盏未熄的烛，窗外一轮月
- **构图**：圆形构图（月光穿过窗棂形成的圆形光影）
- **文字版式**：
  - 标题「静夜思」在顶部横排
  - 诗句「举头望明月，低头思故乡」纵排两列在右侧
  - 作者署名「李白」在诗句下方
  - 朱印在左下角，刻「静夜」二字
- **入画佳句**：举头望明月，低头思故乡

### 《声声慢·寻寻觅觅》—— 李清照

- **诗意关系**：动静 + 时间变化（细雨点点滴滴，从黄昏到夜深）
- **戏眼**：李清照独坐窗前，手指停在帘上，雨点打在窗棂
- **意象**：帘、酒盏、梧桐、满地黄花、雁
- **色彩层级**：
  - 主色：赭红（旧木色）
  - 辅助色：素绢白、落梅红
  - 点睛色：朱砂
- **情绪**：怅惘——不是哭，是心里的空缺一笔一笔画给观者
- **构图**：纵向散点（人物在窗边，景物散在窗外）
- **文字版式**：
  - 标题「声声慢」在顶部
  - 诗句「寻寻觅觅，冷冷清清，凄凄惨惨戚戚」纵排在右侧
  - 作者署名「李清照」在诗句下方
  - 朱印在右下角，刻「寻」字
- **入画佳句**：寻寻觅觅，冷冷清清，凄凄惨惨戚戚（14 字铺满情绪）
- **备选入画佳句**：梧桐更兼细雨，到黄昏、点点滴滴

### 《水调歌头·明月几时有》—— 苏轼

- **诗意关系**：虚实（天上的月与人间的情）+ 情感转折（从问天到接纳）
- **戏眼**：苏轼举杯向月发问
- **意象**：月、酒、酒杯、桂树（想象空间）
- **色彩层级**：
  - 主色：月白
  - 辅助色：剑青、微金
  - 点睛色：朱砂
- **情绪**：旷达——豪放中有温柔，问天但最终接纳
- **构图**：圆形构图（明月）+ 对角线（酒盏指向月）
- **文字版式**：
  - 标题「水调歌头」在左上
  - 诗句「明月几时有？把酒问青天」纵排两列在右下
  - 作者署名「苏轼」在诗句下方
  - 朱印在左下角，刻「月」字
- **入画佳句**：明月几时有？把酒问青天

## 常见陷阱

- **意象贪多**——一首绝句里塞 5 个意象，画面必然散。宁少勿多。
- **情绪写回情绪**——"氛围要孤寂"没有信息量，要写成"画面里只有一个人一壶酒"。
- **佳句选最长最华丽那句**——通常不是。选最贴合戏眼的那句。
- **意象时代错乱**——宋诗里出现汉代的羽扇纶巾，唐诗里出现宋代的瓷盏，都要避免。
- **纯抒情句入画**——"愿君多采撷""但愿人长久"这类纯抒情句，画面表达不了，不要选。
- **文字位置乱放**——文字要放在连续色面上，避开密集景物和暖米白留白。
- **标题过大**——标题不能超过画面 15%，否则喧宾夺主。
- **朱印盖核心意象**——朱印是小点缀，不能盖在核心景物上。
- **诗意关系没找到**——只描述景物不描述关系，AI 会画出散乱的画面。
