# 诗词分析指南

拿到一首古诗词后，按本文件完成 5 项拆解：戏眼、意象、主色、情绪、佳句。所有拆解结果最终都会流进背景图提示词和 HTML 海报模板。

## 核心原则

**不要先找"漂亮场景"，先找"戏眼"。**

戏眼是全诗里那个最小、最具体的动作或瞬间——不是意境、不是主题、不是情绪，是**主角正在做的一个动作**。戏眼找到了，画面就有了立足点；找不到，画面就会散。

**戏眼必须能拍出来。** 抽象概念（孤独、思念、时光）不是戏眼，动作（扶窗、停笔、掩门、端盏、回身）才是。

## 一、找戏眼

### 从以下常见动作里挑

古人诗词里的戏眼高度集中在这些动作上：

- **手部动作**：卷帘、把酒、停笔、掩袖、抚琴、抚剑、掩门、扶栏、拾瓣、拂衣、拢发
- **头部动作**：倚楼、低头、抬眼、回头、照镜、侧耳、听雨、望月、远眺、微蹙
- **身体动作**：独坐、倚床、行舟、策马、夜归、独行、登楼、临水
- **物件反应**：烛焰摇、酒盏倾、笔搁案、帘动风来、花瓣落、钟声远

### 判定标准

好的戏眼同时满足：

1. **具体**——画面里能一眼看到，不用解释
2. **克制**——不是戏剧化动作（不哭不笑不甩袖）
3. **有停顿**——动作处于"将做未做"或"刚做完"的临界点，不是完成态
4. **能承载情绪**——动作本身就能让观者体会到诗里的情绪

### 反面例子

| 反例 | 问题 | 修正 |
|---|---|---|
| "她望着明月思念故乡" | "思念"是情绪不是动作 | "她倚在窗前，手停在窗棂上" |
| "诗人骑马远行" | 太泛，无戏剧张力 | "诗人勒马回头望城，帽带被风吹起" |
| "他在月下饮酒" | 泛古风，任何诗都能套 | "他半斜倚在案边，酒盏倾斜将洒未洒" |

## 二、提取核心意象

从戏眼出发，向四周补 2–4 个具体可拍的意象。意象必须是**名词**——花、月、酒、剑、舟、烛、帘、镜、山、水、竹、柳、梅、鹤、鹿。

### 意象来源优先级

1. **诗里明确出现的**——首选。如《静夜思》"举头望明月"，"月"就是必选意象
2. **诗里隐含但合理推断的**——次选。如"举杯消愁"，"酒盏"就是必选
3. **符合时代质感的道具**——补充。宋代生活美学里：木窗、竹帘、青瓷、矮榻、香炉、素绢、团扇、庭院植物
4. **纯装饰性意象**——不选。不因为"美"就加龙、凤、祥云

### 意象数量控制

- 短诗（绝句、律诗）：2–3 个意象，画面越简越好
- 中词：3–4 个意象
- 长调：4–5 个意象，但要有主次

## 三、定主色调

### 三种定色路径

**路径 A：跟随节气/物候**

| 场景 | 主色调 |
|---|---|
| 春晨 | 嫩绿 + 淡鹅黄 + 海棠粉 |
| 夏午 | 深绿 + 蝉鸣白 + 荷塘红 |
| 秋夕 | 金黄 + 深褐 + 冷灰蓝 |
| 冬夜 | 墨黑 + 月白 + 烛黄 |

**路径 B：跟随情绪**

| 情绪 | 主色调 |
|---|---|
| 旷达豪放 | 铁青 + 剑金 + 石灰 |
| 孤寂清冷 | 墨蓝 + 银白 + 冷灰 |
| 温柔婉约 | 淡鹅黄 + 藕荷 + 象牙白 |
| 怅惘怀旧 | 陈木褐 + 素绢白 + 落梅红 |
| 忧国悲愤 | 铁灰 + 血色 + 墨黑 |

**路径 C：跟随原诗的关键词**

- 有"月"：月白 + 冷蓝
- 有"烛""灯"：烛黄 + 墨黑
- 有"雪"：素白 + 冰青
- 有"酒"：赤褐 + 象牙白
- 有"梅"：雪白 + 落梅红

### 出 2–3 个色，不写颜色形容词

- ✅ "月白 + 冷青蓝 + 烛黄"
- ❌ "淡雅的色调"
- ✅ "低饱和深绿 + 灰白墙面"
- ❌ "充满高级感的莫兰迪色"

## 四、定情绪氛围

用一个词 + 一句具体化描述，把情绪翻译成画面语言。

### 情绪词库

- **旷达**："山月不知心，唯有长啸意"——豪迈但不狂，克制中有释放
- **孤寂**："独坐幽篁里"——不是凄惨，是一个人待得安稳
- **怅惘**："绿肥红瘦"——不是哭，是心里明白春将尽却说不出口
- **清旷**："孤舟蓑笠翁"——冷，但不悲，是自然与人的平静对话
- **婉约**："寻寻觅觅"——不是绝望，是心里的空缺一笔一笔画给观者看
- **悲愤**："凭谁问"——情绪压抑到极限，画面里必须有一处"压不下去"的裂痕

### 情绪不能落回情绪

写完情绪词后，必须补一句"这在画面里长什么样"：

- 错："情绪是孤寂"
- 对："孤寂 → 画面里只有一个人，桌上一盏未喝完的酒，窗外月色清冷，无第二人物"

## 五、挑入画佳句

从全诗里挑 1–2 句进海报。

### 挑选原则

1. **有戏眼的句子优先**——比如"举头望明月"比"床前明月光"更合适
2. **短、有画面感**——10–14 字为宜，不超过 20 字
3. **能代表全诗**——不是最华丽的一句，是最能概括全诗情绪的一句
4. **视觉可承载**——句子里必须有具体的名词（月、山、舟、酒……），全是抽象词的句子不要选

### 反面例子

| 句子 | 是否入画 | 原因 |
|---|---|---|
| "举头望明月" | ✅ | 有动作、有对象、能拍 |
| "疑是地上霜" | ❌ | 是比喻不是动作，画面表达不了"疑" |
| "独在异乡为异客" | ⚠️ | 情绪好但意象稀薄，需配第二句 |
| "每逢佳节倍思亲" | ❌ | 纯抒情，无画面 |
| "绿肥红瘦" | ✅ | 4 个字全是意象，色彩浓、有对比 |
| "知否知否" | ❌ | 语气词，画面无法表达 |

## 拆解示例

### 《静夜思》

- **戏眼**：抬头望月（李白从床上坐起，抬头看向窗外明月）
- **意象**：月、床、窗棂、孤灯
- **主色调**：墨黑 + 月白 + 烛黄
- **情绪**：孤寂——画面里只有一个人，桌上一盏未熄的烛，窗外一轮月
- **入画佳句**："举头望明月，低头思故乡"（两句并列，正好对应两个动作）

### 《声声慢·寻寻觅觅》

- **戏眼**：倚窗听雨（李清照独坐窗前，手指停在帘上，雨点打在窗棂）
- **意象**：帘、酒盏、梧桐、满地黄花、雁
- **主色调**：陈木褐 + 素绢白 + 落梅红
- **情绪**：怅惘——不是哭，是心里的空缺一笔一笔画给观者
- **入画佳句**："寻寻觅觅，冷冷清清，凄凄惨惨戚戚"（首句，14 字铺满情绪）
- **备选入画佳句**："梧桐更兼细雨，到黄昏、点点滴滴"

### 《水调歌头·明月几时有》

- **戏眼**：把酒问天（苏轼举杯向月发问）
- **意象**：月、酒、酒杯、桂树（想象空间）
- **主色调**：月白 + 剑青 + 微金
- **情绪**：旷达——豪放中有温柔，问天但最终接纳
- **入画佳句**："明月几时有？把酒问青天"（起句就是戏眼，10 字够）

## 常见陷阱

- **意象贪多**——一首绝句里塞 5 个意象，画面必然散。宁少勿多。
- **情绪写回情绪**——"氛围要孤寂"没有信息量，要写成"画面里只有一个人一壶酒"。
- **佳句选最长最华丽那句**——通常不是。选最贴合戏眼的那句。
- **意象时代错乱**——宋诗里出现汉代的羽扇纶巾，唐诗里出现宋代的瓷盏，都要避免。
- **纯抒情句入画**——"愿君多采撷""但愿人长久"这类纯抒情句，画面表达不了，不要选。
